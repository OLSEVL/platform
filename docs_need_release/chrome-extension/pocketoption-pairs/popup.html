Активы PocketOption

Alt + QВверх по включённым категориям
Alt + WВниз по включённым категориям

Категории

Включите хотя бы одну категорию — иначе переключать будет нечего.

Фильтры

Оба OTC-фильтра включены — список будет пустым. Оставьте только один.

Порядок обхода внутри категории; на краю списка — переход Валюты → Криптовалюты → Акции (без лишнего сканирования вкладок). Также пропускаются недоступные и с выплатой ниже 75%. Настройки применяются сразу (F5 не нужен).
